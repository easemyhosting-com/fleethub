PR #12's required dependency check failed on the MCP SDK's Hono dependencies. This is a targeted security patch to unblock that check; a full dependency freshness review was not performed.

| Package | Before | After | Reason |
| --- | --- | --- | --- |
| hono | 4.13.14 | 4.13.18 | Patched middleware, CSRF and validation advisories, including GHSA-4m76-xfj5-7975 and GHSA-46wx-v44x-9hh2 |

Overrides apply only to the @modelcontextprotocol/sdk dependency tree. Direct dependency pins and the moderate audit gate remain unchanged. The lockfile changes only these two packages.

All published advisories for both packages were checked against the GitHub Advisory API. npm audit reports zero vulnerabilities after the patch. npm ci, unit tests, typecheck, hygiene and dependency-age checks pass. The production Docker build uses the pinned Node 24.22.1 image, covering the container toolchain rather than relying only on the local Node 26.12.1/npm 11.20.0 checks.

CI runs through GitHub Actions; this patch does not deploy an application. Development CI remains separately blocked by that account's billing/spending limit. A full stack review is due within three to four weeks.
